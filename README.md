# Hexapod Reinforcement Learning Notes

Personal notes on reinforcement learning (PPO) applied to hexapod robotics locomotion. `RL_Note.md` is a ChatGPT-generated reference guide; the remaining notes, images, and code are original author work.

## Folder Structure

- `Hexapod_Reinforcement_Learning.md`, `Reinforcement_Learning.md` — author's RL/PPO notes
- `RL_Note.md` — ChatGPT reference guide
- `simple_RL.py` — example RL script
- `Reinforcement_Learning_Images/` — diagrams referenced in the notes
